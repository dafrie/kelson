An opinionated PaaS package for your Kubernetes cluster.

Git-driven deploys, entirely self-hosted, and layered on top of the Kubernetes API rather than in front of it. Everything kelson creates is a normal object you can inspect with kubectl.

quickstart
$ helm repo add kelson https://charts.kelson.dev
$ helm install kelson kelson/kelson -n kelson-system --create-namespace
kelson-system/controller ready 4.2s
$ kelson deploy --repo github.com/acme/website-static
website-static synced rev 8f2c1ad 3 replicas
