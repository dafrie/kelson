kelson-server is running. The web UI is not in this binary.

The API is served and healthy — this page is what stands in for the UI when a binary was compiled without one. The UI is built by Node and copied into the server's embed directory before compilation, and this build skipped that step.

Build it and rebuild the server:

make ui
make server

Released binaries and the ghcr.io/dafrie/kelson-server images carry the real UI; a binary you built yourself with go build ./cmd/kelson-server does not.

Meanwhile: /healthz reports liveness and the build, and every /kelson.v1alpha1.* route answers as usual. Run the UI against this server from a checkout with npm run dev in ui/.
