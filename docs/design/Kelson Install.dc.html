Getting started

Install kelson

kelson runs as a controller inside your cluster. Installing it takes one Helm release and no external accounts.

1 · Prerequisites

Kubernetes 1.27 or newer, with the CustomResourceDefinition API enabled. Helm 3.12 or newer. Permissions cluster-admin for the install; kelson drops to a scoped role afterwards. Storage A default StorageClass for the revision cache. 2 GiB is enough to start.

2 · Install the chart

Add the chart repository and install into its own namespace.

$ helm repo add kelson https://charts.kelson.dev
$ helm repo update
$ helm install kelson kelson/kelson \
-n kelson-system --create-namespace
The default values install a single controller replica with leader election off. For production, set controller.replicas=2.

3 · Verify

The controller reports ready once its CRDs are established and the revision cache is bound.

$ kelson status
controller ready v0.4.2
crds established 4 resources
cache bound 2Gi standard
apps 0 deployed

If any line reports pending for more than a minute, see Troubleshooting.
